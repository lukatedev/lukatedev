## About me

Student building desktop experiences and developer tools on Linux, learning in public. I like clean interfaces, small tools that do one thing well, and shipping work that other people can install and run.

- 🖥️ **Desktop:** Linux · Wayland · Niri · Quickshell · QML / Qt
- ⚙️ **Tooling:** Rust · Python · Bash · Git · GitHub Actions
- 🧩 **Interested in:** shell customization, extension ecosystems, native UIs, CLI + GUI apps that share one core

## Currently

- 🔨 Building **iNiR Hub**: widgets, themes and community extensions for the iNiR shell.
- 📚 Learning: deeper QML (custom components, performance), idiomatic Rust, and Python tooling.
